# ¿Y tú qué habrías hecho?
**Historia de España desde dentro** — simulación educativa para 2.º de Bachillerato.

## MVP incluido
- Página de inicio con cuatro escenarios: Cortes de Cádiz disponible; otros tres claramente marcados como pendientes.
- Escenario de las Cortes de Cádiz con contexto, cronología, actores y dossier documental.
- Tres alternativas argumentadas, validación de justificación (mínimo 80 caracteres) y segunda decisión ramificada.
- Diferenciación explícita entre hechos documentados, interpretación y resultados hipotéticos.
- Debate, reflexión final y rúbrica de pensamiento crítico de cuatro dimensiones y cinco niveles.
- Modo profesor con guía de sesión, fuentes, debate, rúbrica y explicación de la lógica del árbol.
- Progreso guardado en el almacenamiento local del navegador; no requiere cuentas, API ni servicios externos.
- Diseño responsive y paleta corporativa granate, beige, arena, dorado y marfil.

## Ejecutar
Es una aplicación estática sin dependencias. Abre `index.html` en un navegador o publícala con GitHub Pages desde la raíz de la rama `main`.

## Alcance y rigor histórico
Las opciones no reescriben la historia documentada. Los resultados alternativos se presentan como hipótesis de simulación. Los textos identificados como síntesis didáctica no se presentan como citas literales. La rúbrica en la app ofrece autoevaluación orientativa; no hay análisis automático mediante IA.

## Publicación con GitHub Pages
En el repositorio, abre **Settings → Pages**, elige **Deploy from a branch**, selecciona `main` y la carpeta `/(root)`, y guarda. La disponibilidad pública depende de la configuración del repositorio.
